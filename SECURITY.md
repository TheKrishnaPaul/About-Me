## Reporting a Vulnerability

If you find any security vulnerabilities or issues related to this portfolio website, please follow these steps:

1. Contact me via [email](mailto:thekrishnapaul@gmail.com) or by sending a message through any of the following platforms:
   - [LinkedIn](https://linkedin.com/in/TheKrishnaPaul)
   - [Twitter](https://twitter.com/TheKrishnaPaul)

2. Provide a detailed description of the issue, including steps to reproduce it, if applicable.

I will respond to your report as soon as possible and work on resolving any legitimate concerns. 

## Security Updates

As this is a personal portfolio website, security updates will be applied as needed. You are encouraged to report any concerns immediately so they can be addressed promptly.
